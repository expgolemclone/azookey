# AzooKey custom tabs

The four JSON files in this repository are AzooKey custom-tab definitions:
`abc.json`, `words.json`, `num.json`, and `kana.json`.

These custom tabs are based on the Onishi layout.

## Import on iPhone

1. Make these files available in the iPhone Files app, preferably in iCloud Drive.
2. Open AzooKey's custom-tab settings and choose its file/iCloud importer.
3. Import each JSON file and confirm the tab names `ABC`, `Words`, `☆123`, and `あいう`.
4. Open the AzooKey keyboard in a text field and verify that all four tabs are
   selectable.

Keep the repository JSON files as the source of truth and re-import them after
an intentional change.
